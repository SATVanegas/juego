# Burocracia S.A.

Dinámica de clase sobre la teoría de la burocracia de Max Weber (y las disfunciones de Merton).
Cinco oficinas fabrican pasaportes de papel; la app hace de "Estado" que los recibe, aprueba o rechaza.

**Jugar:** https://satvanegas.github.io/juego/

> En GitHub Pages el juego corre en **modo local**: todo se sincroniza solo entre pestañas
> del mismo navegador (por ejemplo, proyector en una pestaña y moderador en otra).
> Para que varios celulares jueguen a la vez, use la versión de claude.ai.
